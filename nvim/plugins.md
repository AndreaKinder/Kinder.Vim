# Lista de Plugins de Neovim

Aquí hay una lista de los plugins de Neovim configurados en `lua/plugins/`, junto con sus descripciones.

## Plugins Activos

- **saghen/blink.cmp**: Un plugin de completado para Neovim, diseñado para ser performante y funcionar con una configuración mínima.
- **olimorris/codecompanion.nvim**: Un asistente de codificación de IA para Neovim que integra LLMs en tu flujo de trabajo.
- **catppuccin/nvim**: El popular colorscheme Catppuccin.
- **Gentleman-Programming/gentleman-kanagawa-blur**: Una versión con desenfoque del colorscheme Kanagawa.
- **Alan-TheGentleman/oldworld.nvim**: Un colorscheme con una estética de "viejo mundo".
- **rebelot/kanagawa.nvim**: Un colorscheme oscuro inspirado en la famosa pintura de Hokusai.
- **CopilotC-Nvim/CopilotChat.nvim**: Integra el chat de GitHub Copilot en Neovim.
- **zbirenbaum/copilot.lua**: Un popular plugin mantenido por la comunidad para GitHub Copilot.
- **rmagatti/goto-preview**: Proporciona una vista previa para definiciones, declaraciones, implementaciones, etc.
- **echasnovski/mini.hipatterns**: Resalta patrones de texto, como colores HSL.
- **dinhhuy258/git.nvim**: Proporciona integración con Git en Neovim.
- **lazyvim.plugins.extras.linting.eslint**: Soporte para ESLint.
- **lazyvim.plugins.extras.lang.typescript**: Soporte para TypeScript.
- **lazyvim.plugins.extras.lang.tailwind**: Soporte para Tailwind CSS.
- **ibhagwan/fzf-lua**: Una interfaz de búsqueda difusa (fuzzy finding) potente y performante que utiliza fzf.
- **jonroosevelt/gemini-cli.nvim**: Un plugin de Neovim que integra la CLI de Gemini.
- **MeanderingProgrammer/render-markdown.nvim**: Renderiza markdown con varias características dentro de Neovim.
- **williamboman/mason.nvim**: Un gestor de paquetes para herramientas de desarrollo externas como LSPs, linters y formatters.
- **williamboman/mason-lspconfig.nvim**: Un plugin de ayuda que conecta `mason.nvim` y `nvim-lspconfig`.
- **terryma/vim-multiple-cursors**: Un plugin de Vim que permite múltiples cursores para edición simultánea.
- **mfussenegger/nvim-dap**: Implementación del cliente del Protocolo de Adaptador de Depuración (DAP) para Neovim.
- **rcarriga/nvim-dap-ui**: Una interfaz de usuario para nvim-dap.
- **theHamsta/nvim-dap-virtual-text**: Muestra texto virtual para el depurador.
- **stevearc/oil.nvim**: Edita tu sistema de archivos como si fuera un buffer de Neovim.
- **sudo-tee/opencode.nvim**: Una interfaz nativa de Neovim para el asistente de IA `opencode`.
- **folke/trouble.nvim**: Una lista bonita para mostrar diagnósticos, referencias, resultados de Telescope, etc.
- **simrat39/symbols-outline.nvim**: Una vista en forma de árbol para los símbolos en Neovim utilizando el LSP.
- **neovim/nvim-lspconfig**: Configuraciones de inicio rápido para el cliente LSP de Neovim.
- **stevearc/conform.nvim**: Un plugin para formateo de código.
- **chrisgrieser/nvim-rip-substitute**: Un plugin de Neovim para realizar sustituciones con ripgrep.
- **sphamba/smear-cursor.nvim**: Anima el cursor con un efecto de "mancha" o estela.
- **folke/twilight.nvim**: Un plugin de Neovim para atenuar las porciones inactivas del código que estás editando.
- **folke/todo-comments.nvim**: Resalta y busca comentarios TODO, FIX, HACK, etc. en tu código.
- **folke/which-key.nvim**: Muestra una ventana emergente con las posibles combinaciones de teclas.
- **amrbashir/nvim-docs-view**: Un plugin de Neovim para ver documentación.
- **nvim-lualine/lualine.nvim**: Un plugin de statusline rápido y fácil de configurar.
- **b0o/incline.nvim**: Muestra el nombre del archivo actual en una ventana flotante.
- **folke/zen-mode.nvim**: Un plugin para codificar sin distracciones.
- **folke/snacks.nvim**: Un plugin para crear un dashboard personalizable.
- **ThePrimeagen/vim-be-good**: Un plugin diseñado para ayudarte a mejorar tus habilidades en Vim.
- **alexghergh/nvim-tmux-navigation**: Permite una navegación fluida entre Neovim y los paneles de tmux.

## Plugins Deshabilitados

- **akinsho/bufferline.nvim**: Una línea de buffers vistosa (con integración de pestañas) para Neovim.
- **tris203/precognition.nvim**: Ayuda a los usuarios a descubrir y aprender formas más eficientes de navegar dentro de un buffer.
