# markdown.lua

This file configures the `render-markdown.nvim` plugin to improve the display of Markdown files.

## Plugin

- **[MeanderingProgrammer/render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim)**

## Configuration

- **Headings (`heading`):**
    - Displays numeric icons (①, ②, etc.) next to headings.
- **Bullets (`bullet`):**
    - Uses different icons (●, ○, ◆, ◇) for different list levels.
