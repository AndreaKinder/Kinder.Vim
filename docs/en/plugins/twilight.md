# twilight.lua

This file configures the `twilight.nvim` plugin to dim inactive portions of the code.

## Plugin

- **[folke/twilight.nvim](https://github.com/folke/twilight.nvim)**

## Functionality

`twilight` helps to focus on the current context by dimming the rest of the code that is not in focus. It is especially useful in combination with `zen-mode.nvim`.
