# rip.lua

This file configures the `nvim-rip-substitute` plugin to perform project-wide text substitutions using `ripgrep`.

## Plugin

- **[chrisgrieser/nvim-rip-substitute](https://github.com/chrisgrieser/nvim-rip-substitute)**

## Configuration

- **Command:** The plugin is activated with the `RipSubstitute` command.
- **Keybinding:**
    - `<leader>fs` is mapped in normal and visual modes to invoke the plugin's substitution function.
