# copilot-chat.lua

This file configures the integration with GitHub Copilot chat in Neovim.

## Plugin

- **[CopilotC-Nvim/CopilotChat.nvim](https://github.com/CopilotC-Nvim/CopilotChat.nvim)**

## Configuration

- **Prompts:** Defines a table of custom `prompts` in Spanish for common actions such as explaining code, generating tests, refactoring, etc.
- **System Prompt:** Configures a detailed `system_prompt` that defines the AI's persona, specializing in frontend architecture with a particular communication style.
- **Model:** Uses the `claude-3.5-sonnet` model.
- **Window:** Configures the chat window layout in horizontal mode.
- **Mappings:** Defines keybindings to interact with the Copilot chat.
