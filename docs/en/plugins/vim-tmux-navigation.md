# vim-tmux-navigation.lua

This file adds an integration for seamless navigation between Neovim and `tmux` panes.

## Plugin

- **[alexghergh/nvim-tmux-navigation](https://github.com/alexghergh/nvim-tmux-navigation)**

## Functionality

It allows you to use the same keybindings (`Ctrl+h/j/k/l`) to move between Neovim splits and `tmux` panes transparently, creating a unified navigation experience.
