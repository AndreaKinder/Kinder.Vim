# fzflua.lua

This file configures the `fzf-lua` plugin.

## Plugin

- **[ibhagwan/fzf-lua](https://github.com/ibhagwan/fzf-lua)**

## Configuration

- This plugin provides a Lua implementation of `fzf` for Neovim, offering fast and powerful fuzzy finding.
- It depends on `nvim-tree/nvim-web-devicons` to display icons.
