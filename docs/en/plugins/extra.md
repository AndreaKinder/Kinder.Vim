# extra.lua

This file imports a selection of LazyVim "extra" plugins to add additional language and linting functionalities.

## Imported Plugins

- **`lazyvim.plugins.extras.linting.eslint`**: Adds support for `ESLint`.
- **`lazyvim.plugins.extras.lang.typescript`**: Adds support for `TypeScript`.
- **`lazyvim.plugins.extras.lang.tailwind`**: Adds support for `Tailwind CSS`.
