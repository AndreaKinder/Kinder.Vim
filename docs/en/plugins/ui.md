# ui.lua

This file configures several plugins related to the user interface to improve the visual and usability experience.

## Plugins and Configuration

- **[folke/todo-comments.nvim](https://github.com/folke/todo-comments.nvim):**
    - Highlights and searches for `TODO`, `FIX`, `HACK`, etc. comments.

- **[folke/which-key.nvim](https://github.com/folke/which-key.nvim):**
    - Displays a pop-up window with available keybindings.

- **[amrbashir/nvim-docs-view](https://github.com/amrbashir/nvim-docs-view):**
    - Displays documentation in a side view.

- **[nvim-lualine/lualine.nvim](https://github.com/nvim-lualine/lualine.nvim):**
    - Configures a custom statusline with the `tokyonight` theme and several sections to display mode, file information, etc.

- **[b0o/incline.nvim](https://github.com/b0o/incline.nvim):**
    - Displays the current filename, with its corresponding icon and color, in a floating title bar.

- **[folke/zen-mode.nvim](https://github.com/folke/zen-mode.nvim):**
    - Provides a distraction-free coding mode. It is activated with `<leader>z`.

- **[folke/snacks.nvim](https://github.com/folke/snacks.nvim):**
    - Creates a custom startup dashboard with an ASCII logo, keybindings, and lists of recent files and projects.
