# Plugins

This section contains the documentation for the plugins used in Kinder.Vim.

## UI

- [colorscheme.md](./plugins/colorscheme.md) - TokyoNight color scheme.
- [twilight.md](./plugins/twilight.md) - Dim inactive portions of the code.
- [ui.md](./plugins/ui.md) - UI enhancements (Noice, Notify, etc.).
- [which-key.md](./plugins/which-key.md) - Keybinding helper.
- [fzflua.md](./plugins/fzflua.md) - Fuzzy finder.
- [oil.md](./plugins/oil.md) - File explorer.
- [vim-tmux-navigation.md](./plugins/vim-tmux-navigation.md) - Seamless navigation between Vim and Tmux.
- [smear.md](./plugins/smear.md) - Cursor smear effect.

## Editor

- [editor.md](./plugins/editor.md) - Core editor plugins (Neo-tree, Telescope, etc.).
- [extra.md](./plugins/extra.md) - Extra LazyVim plugins.
- [multi-line.md](./plugins/multi-line.md) - Multi-cursor support.
- [rip.md](./plugins/rip.md) - Replacement for `rm`.
- [vim-be-good.md](./plugins/vim-be-good.md) - Game to practice Vim motions.
- [opencode.md](./plugins/opencode.md) - Open code in browser.
- [overrides.md](./plugins/overrides.md) - Custom overrides.

## Coding

- [copilot.md](./plugins/copilot.md) - GitHub Copilot integration.
- [copilot-chat.md](./plugins/copilot-chat.md) - Chat with Copilot.
- [gemini.md](./plugins/gemini.md) - Google Gemini integration.
- [mason.md](./plugins/mason.md) - LSP/DAP/Linter/Formatter manager.
- [nvim-dap.md](./plugins/nvim-dap.md) - Debug Adapter Protocol.
- [neogen.md](./plugins/neogen.md) - Annotation generator.
- [prettier.md](./plugins/prettier.md) - Code formatter.

## Tools

- [markdown.md](./plugins/markdown.md) - Markdown preview and tools.
