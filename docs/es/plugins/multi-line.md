# multi-line.lua

Este archivo añade la funcionalidad de múltiples cursores a Neovim.

## Plugin

- **[terryma/vim-multiple-cursors](https://github.com/terryma/vim-multiple-cursors)**

## Funcionalidad

Este plugin permite crear y utilizar múltiples cursores para editar texto simultáneamente, lo que puede acelerar significativamente las tareas de edición repetitivas.
