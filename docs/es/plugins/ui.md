# ui.lua

Este archivo configura varios plugins relacionados con la interfaz de usuario para mejorar la experiencia visual y de usabilidad.

## Plugins y Configuración

- **[folke/todo-comments.nvim](https://github.com/folke/todo-comments.nvim):**
    - Resalta y busca comentarios `TODO`, `FIX`, `HACK`, etc.

- **[folke/which-key.nvim](https://github.com/folke/which-key.nvim):**
    - Muestra una ventana emergente con los atajos de teclado disponibles.

- **[amrbashir/nvim-docs-view](https://github.com/amrbashir/nvim-docs-view):**
    - Muestra la documentación en una vista lateral.

- **[nvim-lualine/lualine.nvim](https://github.com/nvim-lualine/lualine.nvim):**
    - Configura una barra de estado personalizada con el tema `tokyonight` y varias secciones para mostrar información del modo, el archivo, etc.

- **[b0o/incline.nvim](https://github.com/b0o/incline.nvim):**
    - Muestra el nombre del archivo actual, con su icono y color correspondiente, en una barra de título flotante.

- **[folke/zen-mode.nvim](https://github.com/folke/zen-mode.nvim):**
    - Proporciona un modo de codificación sin distracciones. Se activa con `<leader>z`.

- **[folke/snacks.nvim](https://github.com/folke/snacks.nvim):**
    - Crea un dashboard de inicio personalizado con un logo ASCII, atajos de teclado y listas de archivos recientes y proyectos.
