# fzflua.lua

Este archivo configura el plugin `fzf-lua`.

## Plugin

- **[ibhagwan/fzf-lua](https://github.com/ibhagwan/fzf-lua)**

## Configuración

- Este plugin proporciona una implementación en Lua de `fzf` para Neovim, ofreciendo una búsqueda difusa rápida y potente.
- Depende de `nvim-tree/nvim-web-devicons` para mostrar iconos.
