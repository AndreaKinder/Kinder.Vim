# vim-tmux-navigation.lua

Este archivo añade una integración para una navegación fluida entre Neovim y los paneles de `tmux`.

## Plugin

- **[alexghergh/nvim-tmux-navigation](https://github.com/alexghergh/nvim-tmux-navigation)**

## Funcionalidad

Permite utilizar las mismas combinaciones de teclas (`Ctrl+h/j/k/l`) para moverse entre las divisiones de Neovim y los paneles de `tmux` de forma transparente, creando una experiencia de navegación unificada.
