# smear.lua

Este archivo añade un efecto de "mancha" o estela al movimiento del cursor.

## Plugin

- **[sphamba/smear-cursor.nvim](https://github.com/sphamba/smear-cursor.nvim)**

## Funcionalidad

Este es un plugin puramente estético que crea un rastro visual al mover el cursor, similar a una mancha.
