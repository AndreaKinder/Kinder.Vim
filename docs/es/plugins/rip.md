# rip.lua

Este archivo configura el plugin `nvim-rip-substitute` para realizar sustituciones de texto en todo el proyecto utilizando `ripgrep`.

## Plugin

- **[chrisgrieser/nvim-rip-substitute](https://github.com/chrisgrieser/nvim-rip-substitute)**

## Configuración

- **Comando:** El plugin se activa con el comando `RipSubstitute`.
- **Atajo de Teclado:**
    - Se mapea `<leader>fs` en modo normal y visual para invocar la función de sustitución del plugin.
