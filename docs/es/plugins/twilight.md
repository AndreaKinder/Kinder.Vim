# twilight.lua

Este archivo configura el plugin `twilight.nvim` para atenuar las porciones de código inactivas.

## Plugin

- **[folke/twilight.nvim](https://github.com/folke/twilight.nvim)**

## Funcionalidad

`twilight` ayuda a concentrarse en el contexto actual atenuando el resto del código que no está en el foco. Es especialmente útil en combinación con `zen-mode.nvim`.
