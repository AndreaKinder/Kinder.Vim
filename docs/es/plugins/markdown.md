# markdown.lua

Este archivo configura el plugin `render-markdown.nvim` para mejorar la visualización de archivos Markdown.

## Plugin

- **[MeanderingProgrammer/render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim)**

## Configuración

- **Encabezados (`heading`):**
    - Muestra iconos numéricos (①, ②, etc.) junto a los encabezados.
- **Viñetas (`bullet`):**
    - Utiliza diferentes iconos (●, ○, ◆, ◇) para los distintos niveles de las listas.
