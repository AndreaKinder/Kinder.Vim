# copilot-chat.lua

Este archivo configura la integración con el chat de GitHub Copilot en Neovim.

## Plugin

- **[CopilotC-Nvim/CopilotChat.nvim](https://github.com/CopilotC-Nvim/CopilotChat.nvim)**

## Configuración

- **Prompts:** Define una tabla de `prompts` personalizados en español para acciones comunes como explicar código, generar pruebas, refactorizar, etc.
- **System Prompt:** Configura un `system_prompt` detallado que define la persona de la IA, especializándose en arquitectura frontend con un estilo de comunicación particular.
- **Modelo:** Utiliza el modelo `claude-3.5-sonnet`.
- **Ventana:** Configura la disposición de la ventana del chat en modo horizontal.
- **Mapeos:** Define atajos de teclado para interactuar con el chat de Copilot.
