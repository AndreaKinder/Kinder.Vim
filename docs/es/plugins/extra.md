# extra.lua

Este archivo importa una selección de plugins "extra" de LazyVim para añadir funcionalidades adicionales de lenguajes y linting.

## Plugins Importados

- **`lazyvim.plugins.extras.linting.eslint`**: Añade soporte para `ESLint`.
- **`lazyvim.plugins.extras.lang.typescript`**: Añade soporte para `TypeScript`.
- **`lazyvim.plugins.extras.lang.tailwind`**: Añade soporte para `Tailwind CSS`.
