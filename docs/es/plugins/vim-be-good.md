# vim-be-good.lua

Este archivo incluye un plugin para ayudarte a mejorar tus habilidades en Vim.

## Plugin

- **[ThePrimeagen/vim-be-good](https://github.com/ThePrimeagen/vim-be-good)**

## Funcionalidad
