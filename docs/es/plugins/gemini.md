# gemini.lua

Este archivo configura el plugin `gemini-cli.nvim` para interactuar con Gemini.

## Plugin

- **[jonroosevelt/gemini-cli.nvim](https://github.com/jonroosevelt/gemini-cli.nvim)**

## Configuración

- **`split_direction = "vertical"`**: Configura la ventana de Gemini para que se abra en una división vertical.
