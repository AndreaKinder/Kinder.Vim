# Plugins

Esta sección contiene la documentación de los plugins utilizados en Kinder.Vim.

## Interfaz (UI)

- [colorscheme.md](./plugins/colorscheme.md) - Esquema de colores TokyoNight.
- [twilight.md](./plugins/twilight.md) - Atenúa partes inactivas del código.
- [ui.md](./plugins/ui.md) - Mejoras de la interfaz (Noice, Notify, etc.).
- [which-key.md](./plugins/which-key.md) - Ayuda de atajos de teclado.
- [fzflua.md](./plugins/fzflua.md) - Buscador difuso.
- [oil.md](./plugins/oil.md) - Explorador de archivos.
- [vim-tmux-navigation.md](./plugins/vim-tmux-navigation.md) - Navegación fluida entre Vim y Tmux.
- [smear.md](./plugins/smear.md) - Efecto de estela del cursor.

## Editor

- [editor.md](./plugins/editor.md) - Plugins principales del editor (Neo-tree, Telescope, etc.).
- [extra.md](./plugins/extra.md) - Plugins extra de LazyVim.
- [multi-line.md](./plugins/multi-line.md) - Soporte para múltiples cursores.
- [rip.md](./plugins/rip.md) - Reemplazo para `rm`.
- [vim-be-good.md](./plugins/vim-be-good.md) - Juego para practicar movimientos de Vim.
- [opencode.md](./plugins/opencode.md) - Abrir código en el navegador.
- [overrides.md](./plugins/overrides.md) - Sobrescrituras personalizadas.

## Código (Coding)

- [copilot.md](./plugins/copilot.md) - Integración con GitHub Copilot.
- [copilot-chat.md](./plugins/copilot-chat.md) - Chat con Copilot.
- [gemini.md](./plugins/gemini.md) - Integración con Google Gemini.
- [mason.md](./plugins/mason.md) - Gestor de LSP/DAP/Linter/Formatter.
- [nvim-dap.md](./plugins/nvim-dap.md) - Protocolo de Adaptador de Depuración.
- [neogen.md](./plugins/neogen.md) - Generador de anotaciones.
- [prettier.md](./plugins/prettier.md) - Formateador de código.

## Herramientas (Tools)

- [markdown.md](./plugins/markdown.md) - Vista previa y herramientas de Markdown.
