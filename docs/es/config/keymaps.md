# keymaps.lua

Este archivo contiene los atajos de teclado personalizados para Neovim.

## Mapeos Personalizados

- **`Ctrl+b` (Modo Inserción):** Borra hasta el final de la palabra sin salir del modo inserción.
- **`Ctrl+c`:** Escapa de los modos inserción, normal y visual.
- **Navegación Tmux:** Atajos `Ctrl+h/j/k/l` para navegar entre paneles de Neovim y Tmux.
- **`leader+fe`:** Abre el explorador de archivos (Oil).
- **`leader+ag`:** Alterna la interfaz de línea de comandos de Gemini.
- **`Ctrl+s` (Modo Normal):** Guarda el archivo actual con una notificación personalizada.
- **`leader+sg` (Modo Visual):** Busca el texto seleccionado en el proyecto.
- **`leader+sG` (Modo Visual):** Busca el texto seleccionado desde el directorio raíz del proyecto.
- **`leader+md`:** Elimina todas las marcas.

El archivo también deshabilita algunas combinaciones de teclas predeterminadas para evitar conflictos.
